FIX 下单助手 · 下载与使用说明

Windows 桌面客户端，用于 FIX 协议下单、撤单和成交回报查看。免安装、单文件，连接参数全部界面可配。

一、下载

➡ 打开下载页（在页面上点「下载」按钮）

  • 下载页打不开时用直链（国内加速）：FIX-Order-Desk.exe
  • GitHub 原版：Releases 页面

校验方法：certutil -hashfile FIX-Order-Desk.exe SHA256

二、安装与运行

  1. 把 exe 放到不含中文的目录，例如 D:\FIX（路径含中文时 QuickFIX 可能读不到配置）。
  2. 双击运行，无需安装 Python 或其他依赖。
  3. 首次启动会在 exe 同级目录生成 config/、dict/、logs/、store/、runtime/。
  4. Windows 提示“未知发布者”时，点「更多信息 → 仍要运行」；若杀毒软件误报，请把 exe 加入信任。

三、首次配置

  1. 打开「连接配置」页。
  2. 填写服务器地址、端口、SenderCompID、TargetCompID、SenderSubID；版本号、心跳、重连、交易时段、数据字典、序号目录保持默认即可。
  3. 点「保存」，下次启动自动带出；也可以用「另存为」保存多套档案（例如生产 / UAT）。
  4. 点「连接交易网关」，顶部状态变成绿色「已登录」后即可下单。

换网关或账号后如果登录被拒，点「重置序号并重连」。

四、下单

  • 所有字段都能从下拉里选，也能直接键盘输入；数量、价格聚焦时会自动全选，直接输入即覆盖。
  • 选择交易标的会自动带出交易市场。
  • 选「市价」会自动清空价格；限价单必须填价格。
  • 附加字段用于写非标准 tag，例如 11000=3（融券标志）。
  • 「预览报文」可以先看即将发出的 FIX 报文，不会真正发送。

五、委托列表与回报

  • 右侧「委托列表」每行是一笔委托的最新状态，不会把每条成交回报单独列一行。
  • 双击某一行（或右键 →「查看回报明细」）可以看到这笔委托的完整时间线：报单 → 委托回报 → 成交回报 / 撤单请求 / 撤单回报 / 撤单拒绝；点其中任意一条，下方显示对应的原始 FIX 报文。
  • 撤单：在列表里选中一笔进行中的委托 → 点「撤单选中」→ 确认。委托号、代码、方向、账号都取自这一行，不需要手输；「撤单备注」会写进 58 字段。

六、查询与其他页签

  • 查询：资金 FD、持仓 AN、额度 SC，结果按应答类型分表，可切到「原始报文」看全文。
  • 字段字典：维护所有下拉选项和附加字段预设，保存后立即生效。
  • 运行日志：所有收发报文、成交回报、错误，可按类别过滤并导出。
